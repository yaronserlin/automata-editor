How to use Automata Editor

Create & connect

  • Double-click the canvas (or press N): add a state.
  • Draw a transition: hold Shift and drag from one state to another.
  • Or double-click a state, then drag to the target state, or release and click the target. Click the same state for a self-loop; click empty space or press Esc to cancel. A banner on the canvas shows when you are drawing.
  • Click a state or transition: edit its name, label, or start/accept flags in the panel.

Move & view

  • Drag a state: move it (it snaps into line with its neighbours).
  • Drag a transition's label: bend it. Drag the start arrow to rotate it.
  • Drag empty space: select several states.
  • Ctrl + scroll or the +/− buttons: zoom. Alt + drag or middle-click drag: pan.

Test an input

  • Type a string in Test input and press Enter or Run to see if it is accepted.
  • Use the step and play buttons to watch the active states light up one symbol at a time.
  • Works for DFAs and NFAs, including ε-transitions. Leave the input empty to test the empty string. Separate multi-character symbols with spaces (10 01).

Labels (LaTeX)

  • Names and labels are rendered as math: q_0 → q₀, \epsilon → ε, \Sigma → Σ.
  • Use braces for longer subscripts: q_{10}.
  • If a label is not valid LaTeX, the panel explains what is wrong.

Undo & saving

  • Ctrl+Z undo, Ctrl+Shift+Z (or Ctrl+Y) redo. On a Mac, use ⌘. The buttons in the canvas corner do the same.
  • Delete / Backspace: delete the selection (undo brings it back).
  • Your diagram is saved in this browser automatically. Use Save to download a project file you can Load anywhere.

Touch screens

  • Double-tap the canvas: add a state.
  • Double-tap a state, keep your finger down, and drag to the target; or lift and tap the target.
  • Tap a state or transition to edit it. Drag a state to move it.
  • Pinch to zoom; move two fingers together to pan.

Keyboard (no mouse needed)

  • N: create a state in free space near the view center
  • [ / ]: select previous / next state or transition
  • Arrow keys: move selected state(s) (Shift for 1px)
  • Enter: start / confirm drawing a transition
  • + / -: bend the selected transition
  • 0: reset the selected transition's shape
  • Escape: cancel drawing / deselect
  • Ctrl+Z / Ctrl+Shift+Z: undo / redo
