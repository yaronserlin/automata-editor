Automata Editor

Design, edit, and export deterministic and non-deterministic finite automata.

100%

Properties

Create & Edit

  • 🖱️ Double-click canvas: Create Node
  • 🔗 Double-click node: Draw Edge / Edit
  • 👆 Double-click edge: Edit properties

Move & Select

  • 👆 Click: Select Node / Edge
  • ✋ Drag node: Move
  • 📦 Drag empty space: Multi-select

Actions

  • ⌨️ Delete / Backspace: Delete selection
  • 🔍 Ctrl + Scroll (or Buttons): Zoom Canvas
  • 🖐️ Middle-Click / Alt+Drag: Pan Canvas

Keyboard (no mouse needed)

  • N: Create node at view center
  • [ / ]: Select previous / next node or edge
  • Arrow keys: Move selected node(s)
  • Enter: Start / confirm drawing an edge
  • + / -: Bend selected edge's curve
  • 0: Reset selected edge's shape
  • Escape: Cancel edge draw / deselect
